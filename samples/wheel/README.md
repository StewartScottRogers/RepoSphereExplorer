# csvstats-1.0.3-py3-none-any.whl

A Python wheel: a zip whose `.dist-info/WHEEL` says which wheel format
it is and whether it is pure Python, and whose `METADATA` carries the
requirements, the extras and the Python it needs.

The compatibility tags are in the **file name**, not inside the archive:
`py3-none-any` means any Python 3, no application binary interface, any
platform. A wheel that will not install is usually one whose tags do not
match, so the pane reads them.
