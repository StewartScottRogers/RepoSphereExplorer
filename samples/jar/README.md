# csvstats-1.0.3.jar

A Java archive: a zip whose `META-INF/MANIFEST.MF` names a main class, a
class path, and specification and implementation versions.

It is signed — `META-INF/FLOOR.SF` and `FLOOR.RSA` — and declares a
service in `META-INF/services/`. Both are things a reader wants told
apart from ordinary members.
