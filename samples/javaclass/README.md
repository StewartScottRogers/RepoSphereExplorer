# Column.class

A Java class file, and the nested class it compiles alongside.

`Column.java` is the source both were built from. It is here because a
class file is unreadable without it: the class file has the shape - the
constant pool, the descriptors, the access flags - and the source says
what that shape meant.

Between them the two classes exercise a superclass, an interface, a
constant field, an instance field, a constructor, a generic method with
its `Signature` attribute, a runtime-visible annotation, and an
`InnerClasses` entry pointing each way.
