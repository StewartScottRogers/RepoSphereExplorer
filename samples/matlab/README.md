# csvstats

Summary statistics for a column of readings, in MATLAB.

    >> [m, d, n] = csvstats([1 2 3])
    >> analyse

`csvstats.m` is a function file; `analyse.m` is a script written in
sections. The two local functions in `csvstats.m` take inputs and check
none of them, and `analyse.m` calls into two toolboxes. Both are left
that way so the file pane has something to warn about.

The `.m` extension belongs to Objective-C in this registry, so these
files are recognised by what is in them rather than by their name.
