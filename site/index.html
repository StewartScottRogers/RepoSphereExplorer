RepoSphereExplorer

A dark-factory-built file explorer: a three-pane TUI and native GUI over a local service, one plugin per file type.

Download

Binaries are unsigned (no code-signing budget yet), so Windows SmartScreen and macOS Gatekeeper will warn on first run. tui and gui each auto-launch service if it isn't already running — keep the files together in one folder.
