Repos Explorer

A dark-factory-built front door to your development workspace: it opens at your Repos Directory, tells you which folders are working copies and where each one came from, and previews what is inside them. A three-pane terminal user interface and native graphical user interface over a local service, one plugin per file type.

Download

Binaries are unsigned (no code-signing budget yet), so Windows SmartScreen and macOS Gatekeeper will warn on first run — see the macOS panel for what to do about it. tui and gui each auto-launch service if it isn't already running — keep the files together in one folder.

    macOS Detected

    • ReposExplorer.dmg — the application, drag it to Applications

    The disk image holds Repos Explorer.app and a shortcut to /Applications: drag one onto the other. The application is not signed with an Apple Developer ID, so the first launch has to be right-click → Open → Open — a double-click is refused by Gatekeeper with “cannot be opened because the developer cannot be verified”. After that first time, it opens like anything else. The loose executables below are for the terminal application and for scripting.

    Linux Detected

      On Linux, one step: ReposExplorer-x86_64.AppImage — download it, make it executable, run it. It carries the graphical application, the terminal application and the service in one file, installs nothing, and is removed by deleting it.

      Or install with a script that checks every file against the release's signed manifest before placing anything, adds the desktop entry and icon (Linux) or the Start menu and Settings > Apps entries (Windows), and uninstalls cleanly: install.ps1 (Windows) or install.sh (Linux and macOS).
